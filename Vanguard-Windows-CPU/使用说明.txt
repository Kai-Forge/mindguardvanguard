御郁先锋 — Windows CPU 免安装版

【打开方法】
1. 把 ZIP 完整解压到一个可写目录，例如 D:\Vanguard。不要在压缩包里直接运行。
2. 双击 Start.cmd。不需要安装 Python，不需要安装 CUDA，也不需要 NVIDIA 显卡。
3. 保留启动窗口。模型首次加载可能需要数分钟；加载完成后自动打开默认浏览器。
4. 点击“开启实时识别”，允许浏览器访问摄像头和麦克风。
5. 结束时先点击网页“停止”，再在启动窗口按 Ctrl+C 关闭服务。

【电脑要求】
Windows 10/11、64 位 x86 处理器。推荐 16GB 内存及 8GB 可用磁盘空间。
本包不适用于 macOS、Linux 或 Windows ARM 原生运行。
模型、Python 和第三方依赖均随包提供，推理不需要联网。
使用当前版本的 Edge 或 Chrome。低配置电脑推理较慢，不保证实时窗口跟得上。
启动窗口实际显示本机地址；若 8765 已占用，会选择后续空闲端口。

【输入与结果】
摄像头、麦克风来自当前这台电脑，推理也在当前电脑完成。
EGG 尚无实时设备接入，因此实时 EGG 与三路融合保持无结果。
文件模式可以选择实际人脸图像，以及双通道 WAV（第 1 通道语音，第 2 通道 EGG）。
单声道音频仅运行语音模型。三路都有效时，才显示三路加权融合。
融合前请确认图像、语音、EGG 属于同一人、同一时间段。
预测供展示和研究，不是医学诊断。

【保存在哪里】
默认不保存原始采集。勾选“同时保存采集数据”后，需填写参与者编号。
保存位置：本包目录下 user_data\captures。
日志位置：user_data\logs；语音模型日志：app\trimodal\outputs\emotion2vec_worker.log。
不要将自己的采集记录再次转发给别人；本次初始分发包不包含数据库或用户录音。

【如果打不开】
请先双击 Start.cmd，不要直接双击 app\trimodal\web\index.html。
等待启动窗口出现模型加载结果。若浏览器未自动打开，复制启动窗口内的地址到 Edge/Chrome。
关机后需要再次双击 Start.cmd；网页文件本身无法替代后台模型服务。
若提示缺少 DLL、模型加载失败，保存启动窗口报错和模型日志发给项目维护者。
本包在打包电脑的独立 CPU 环境中验证；不同硬件、杀毒策略和系统组件仍可能影响运行。

【模型来源】
语音：emotion2vec+ base 官方预训练模型，采用 FunASR 加载。
图像：OpenCV Zoo MobileFaceNet 表情模型与 YuNet 人脸检测。
EGG：项目现有 EGG-only CNN–BiLSTM 权重。
第三方来源、作者及许可保留在 THIRD_PARTY_NOTICES.md、app\trimodal\assets 和 runtime 的包元数据中。
